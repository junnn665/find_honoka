# ほのかを探せ！！

たくさんの顔の中から、手配書の「ほのか」を探すゲームです。身内専用なので、顔写真は合言葉で暗号化してあります。

- **ひとりで遊ぶ**：見つけると +5秒、まちがえると −10秒。0秒になったら終わり
- **対戦**：4ケタの部屋番号・招待リンク・QRコードで集まり、10・20・30ラウンドから選んで早押しで勝負。まちがえると1.5秒タップできなくなる
- 盤面にほのかは必ず1人だけ。レベルが上がると顔が増え、動き・白黒・回転などで難しくなる
- **特殊ラウンド**：ほのかが2人いる／全員さかさま／手配書が顔の一部だけ（ひとりで遊ぶはレベル4・7・10…、対戦は3・6・9ラウンド目）
- **妨害**：対戦で確保した人は、次のラウンドの最初の3.5秒、ほかの人（チーム戦なら相手チーム）の画面を白黒ぼかし・大ゆれ・霧・さかさまにする
- **チーム戦**：待合室でホストが「チーム戦」を選ぶと赤と青に分かれ、合計で勝負
- **写真の管理**：タイトルの「写真を追加・削除」から写真を足したり消したりできる（全員に反映されるのは GitHub に上書きしたときだけ）。できた `faces.enc.json` を GitHub の `public/` に上書きすれば全員に反映
- **ほのか図鑑**：確保した写真がコレクションとして集まる（この端末に保存）
- **ボス面**：ひとりで遊ぶは5レベルごと、対戦は最終ラウンド。顔が大量に高速で動く（ひとりで遊ぶは撃破で+10秒）
- **ランキング**：ひとりで遊ぶの自己ベストを全員／フレンドで比べる（送るのは名前と数字だけ）
- **フレンド**：フレンドコードや一緒に遊んだ人から登録。オンラインかどうかが見え、招待すると相手の画面に「参加する」が出る
- **ホーム画面に追加**すると全画面のアプリとして起動。一度開けば通信なしでも「ひとりで遊ぶ」ができる

## ファイル構成
- `public/` … 公開されるゲーム本体（Cloudflare Pages の出力先）
- `tools/` … 暗号化ツール（公開されない）

## プライバシーのしくみ
- 顔写真は AES-GCM で暗号化して `faces.enc.json` に入れてある（鍵は合言葉から PBKDF2 で作る）。合言葉を知らない人には写真が見えない
- 元の写真はリポジトリに入れていない（位置情報などの EXIF も消してある）
- オンライン対戦で Firebase に送るのは「なまえ」と「勝ち負け」だけ（trump_dual と同じデータベースの `rooms/honoka-<番号>` を使う）
- 検索エンジンに載らないよう `noindex` を指定
- 合言葉を入れた人は写真を保存できてしまうので、合言葉は信頼できる人にだけ教えること

## 合言葉を変える
元の顔画像フォルダ（リポジトリの外）を用意して次のコマンドを実行し、できた `public/faces.enc.json` を上書きする：
```
node tools/encrypt.mjs "新しい合言葉" ../private/crops ../private/decoys
```
